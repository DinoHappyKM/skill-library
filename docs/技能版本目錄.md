# 技能版本目錄

skills-catalog.json是發佈來源目錄，不是已安裝清單。role區分menu、teacher_tool、student_skill；學生不含I0000。必要欄位包含id/name/slug/version、SKILL/YAML路徑、SHA256、bytes、分類及required_files。未宣告版本null，不從README或manifest猜。

SHA256基於UTF8原始bytes。normalized_text_sha256只去UTF8 BOM及CRLF/CR轉LF，不刪其他空白；只能據實回報正規化核對，不能冒稱原bytes一致。

產生器每次解析HEAD為commit，從同一commit取得目錄和全部來源。source_ref只是查詢入口；提示詞是當時快照，下次重新產生才取得最新技能。

schema：schemas/skills-catalog.schema.json。km-installed-skills.json是每位學生外掛的回執，建議schema_version、source_repository、skills（按slug，包含id/version/source_commit/source_hashes/installed_hashes）。必須核對實際檔案，不只相信回執；無可信舊版基準先確認。主選單分別記模板及合併後實際hash。

未來必要references／圖片資產如實列required_files，不為兩檔刪功能；工作主檔仍在各原Pxxx，P012只管理來源設定及I0000。
