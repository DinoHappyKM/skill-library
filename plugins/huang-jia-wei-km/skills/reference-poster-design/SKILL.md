# I0008｜參考圖海報設計

版本：0.1.0。以使用者喜歡的參考圖為設計依據，完成FB／IG／LINE社群圖、電影海報、廣告DM或網頁Banner。先讓人理解想傳達什麼，再用構圖、文字與色彩襯托；不是把所有元素填滿。廣告成效與美感需由使用者實際驗收，不承諾流量或成交。

## 入口與進度

流程：收素材與用途 → 拆參考圖 → 確認一張設計卡 → 出一張樣稿 → 校對微調 → 交付。
每輪說明目前在做哪一步、下一步只需回什麼。沿用已回答資料，不重新發問卷。直接改既有海報時保留已確認設計，只問缺少且會改變結果的資訊。

如果環境提供真正的選項工具，可用來問用途、比例或風格偏好；否則顯示編號讓使用者輸入數字或填空。不把文字選單、Markdown或圖片宣稱為可點選的原生介面，不要求MCP或付費表單。

## 1｜最多三組啟動資料

一次只收這三組，使用者可用一句話回答；已知欄位先填好，只補缺項。

1. **做什麼、給誰看？** ①社群宣傳 ②電影／故事海報 ③廣告／活動DM ④網頁Banner ⑤其他。再說一句主題與對象。故事／形象任務不強迫商業USP或痛點。
2. **喜歡哪種感覺、用哪些素材？** 上傳一至三張最有代表性的喜好圖（更多也可），及要使用的人像／產品／Logo。請標「參考A／B、產品、人物、Logo」；同一張可兼任多種角色。已明說角色就不再確認，不憑上傳先後猜角色。
3. **尺寸與文字？** ①1:1 ②4:5 ③9:16 ④16:9 ⑤自訂寬×高。填主標、次標；內文與CTA選填，可填「請幫我擬」或「不要」。有指定平台欄位或印刷公分時用它，不把通用比例當平台最新官方規格。

可提供單一填空區塊，手機直接複製；未知填未定即可：
```text
用途／對象：
主題／想讓人感受到：
參考A想借用：／參考B想借用：
素材：人物／產品／Logo／無
尺寸或比例：
主標：／次標：
內文：無／指定文字
CTA：不要／指定文字／請建議
```

使用者不知道風格時提供：[圖靈感](https://pin.it/5y5rEK2Jd)、[海報靈感](https://pin.it/1dLcENjC0)。請他截圖或上傳喜歡的圖；連結看不到、需登入或圖片不清楚時如實說明，不能假裝看見。暫無參考圖：可先整理文案；只有使用者同意由你提案時才給二個簡短方向，標為建議而非學到的喜好。

缺資料不必阻擋全部：沒有Logo可省略；沒有照片可經確認改用抽象或插畫。指定要用的真人／產品原圖未到，先等原圖，不另造替身。商業條件、價格、日期、網址不得猜填。

## 2｜看懂參考，而非照搬表面

必須先實際查看參考圖和原始素材。對每張標出「看得到的特徵」與「你的解讀」，用白話短句說明，不寫冗長分析。讀不清的字或看不到的局部明確標示。

檢視：
- **視線與構圖**：第一眼焦點、第二眼資訊、重心、比例、裁切、前中後景、對齊軸、文字區與負空間。留白可以是暗部、天空、紋理或低細節區，不等於白色背景；不強制固定百分比。
- **圖像語言**：攝影／插畫／拼貼、線條與筆觸、顆粒、紙感、輪廓軟硬、光源、陰影方向、景深。元素必須服務內容，不為裝飾堆光暈、粒子、浮雕、貼紙或漸層。
- **色彩與情緒**：主色、輔色、點綴色、明度、彩度、冷暖、面積、局部反差、膚色／產品真色。從圖中估計的色碼只稱估計；工具實際採樣才說取色。
- **文字設計**：主標、次標、內文各自的字族傾向、字重、字寬、字距、行距、排列、大小對比、材質與背景關係。無法辨認精確字型時描述「粗明體／窄黑體／手寫筆觸」而非捏造字型名稱。

複合參考必須指定分工，例如「A借構圖與留白，B借主標筆觸，C借低彩度暖色」，先選一張主參考統一全圖。衝突時提出一個取捨選項，不平均混合成雜燴。學習設計特徵，不帶入他人的Logo、人物、商標文案、簽名或水印；使用者提供有權使用的內容另行辨識。

## 3｜把表象連到內涵

將主題濃縮為「畫面看見＿＿，但想讓觀眾感受到＿＿」。內涵由使用者主題／故事推導；不足時只問一句「你希望他看完感覺什麼？」不編造人物遭遇、產品功效或促銷。

選一種主要呼應方式即可：大小／疏密對比、明暗、虛實、遮露、物件關係、負空間、視線／光線方向、材質反差或字與圖的形態呼應。說明它為何服務這次訊息；不要一律加象徵物，避免把希望、孤獨、高級等抽象詞直接變成慣用特效。

配色以參考圖與訊息優先，以下只用來討論，不是情緒定律：
- 高明度低彩度可輕盈清新，但不要白到失去文字辨識。
- 明亮高彩度可活潑有力；只讓需要的區域飽和，不全圖拉滿。
- 中明度、柔和土色與自然材質可溫暖手作，不強迫每個養生品牌用綠色。
- 暗底加小面積亮點可穩重、精緻，也可能懸疑；由光質、構圖、文案及故事共同決定。
- 電影感不是固定橙青濾鏡；可乾淨、低反差、冷靜、粗粒或濃烈，依參考指定。商品與膚色保真優先於整片套濾鏡。

## 4｜三層文字與花字設計

先確定上圖文字，再生成。主標短而有力，約4～12字可作起點；不為8字限制改掉專有名稱、故事語意或必要條件。使用者已定文字照錄；未定時最多給兩個主標搭配次標供選，不能自行把兩組都放上圖。

**主標／花字**：依參考選普通排字、字形設計或兩者結合。明體／宋體的粗細對比、黑體的力量、圓體的親切、手寫的速度與不規則都必須配合訊息。花字可處理筆畫收尾、局部連接、傾斜、疊壓、弧線、切割、留空、紙感或油墨肌理；每張選少量有效處理，不預設描邊＋厚陰影＋金屬3D。先保字形和閱讀次序，再做藝術化，不把筆畫改成錯字。

**次標**：補足主標未說完的內容，透過字族、對齊或少量用色呼應；降低一級視覺重量，不跟主標用同等花字效果競爭。可使用清楚黑體呼應明體／手寫主標，也可同字族不同字重，不硬規定混搭。

**內文／必要資訊**：有需求才放，用易讀黑體、圓體或合適正文字族；按行長與手機縮圖調整字級、字距、行距。長內文建議移至貼文或另頁，請使用者選擇；日期、價格、資格等關鍵資訊不可默默刪去。Logo字樣保留原圖，不重造品牌字。

在設計卡列出每層「確切文字／字形風格／重量與大小關係／排列位置／與圖的呼應」。可以用主標100、次標約35～50、內文約22～30作初步相對尺度，但必須依尺寸、字數與實際閱讀修正，不能當通用像素規格。字型名稱／授權只有核實後才承諾；純生成圖片不保證精確字型、可編輯字層或可商用字型檔。

CTA由目的決定：形象與電影海報可不要；要轉換才問具體行動，沒有連結不造網址或QR。內文、優惠貼紙、標語、英文小字與署名都不得在確認清單外自動加入。

## 5｜一張設計確認卡

以一個手機易讀的短清單確認，不先出三張完整圖：
- 用途／對象與尺寸。
- 素材角色：哪張用於參考、哪張真實入圖、Logo要不要上圖。
- 表象→內涵與一個主要呼應方法。
- 參考A／B的借用分工、留白位置、視線順序。
- 主／輔／點綴色與明暗彩度、光質／材質；哪些顏色需保真。
- 主標／次標／內文／CTA的確切文字、字體／花字方式與層級。

結尾只需：「回1照這版做；回2並說要改哪裡。」資料足夠且使用者已明確核准相同設計，可直接生成，不重複確認。若修改只涉及已核准範圍內一處，保留其他部分。

## 6｜生成與校對

使用實際可用的圖片生成／編輯工具製作一張完整樣稿。必須將已確認的參考圖與原始素材傳入工具；不能只寫文字描述卻遺漏附件。將圖號、角色、構圖、文字白名單、字形、留白、顏色與禁止變動項寫清楚。具體工具名稱依環境，不把Skill當成新增圖片權限。

指定原圖時走編輯／合成，保留真人身分、產品輪廓／包裝／標籤及Logo。可按已確認範圍去背、裁切、調光；不以相似生成圖替換。工具無法精準保留Logo或產品細節時改採可用的原圖疊放流程，或交背景＋定位說明並清楚標未完成，不宣稱逐像素保真。品牌Logo是素材，不是任意生成的文字。

外掛的DinoH圖示只用於工具識別，不自動蓋在學員、客戶或電影海報上。海報用使用者確認的品牌Logo；未要求不硬塞作者Logo。

出圖後實際看圖檢查：
1. 第一眼是否只有清楚主焦點？第二眼是否接到次標？留白是否仍存在？
2. 主標花字、次標與內文是否同方向但有層級？縮小到手機觀看時仍可辨識，未實際縮圖時不要稱測過。
3. 上圖文字逐字對照白名單，無漏字、錯字、簡體、亂碼或多餘英文。圖片中看不清的字不宣稱已校對。
4. 真實人物／商品／Logo有無變形、換圖、改色、假標籤？配色是否符合參考而非制式重濾鏡？
5. 比例、裁切與安全邊界是否符合這次用途？有檔案工具時查實際像素；印刷須另核對公分、解析度、出血與印廠規格，不能只改DPI就稱可印。

發現實際問題只改失敗處，先保留已確認文字及構圖。首次樣稿後最多兩次針對性修正，仍失敗就交原結果、問題與下一步，不無限重畫。此上限不阻止使用者另授權新方向。

若沒有出圖工具：如實交完整可複製的製圖提示詞與文字／排版表，標示「尚未生成圖片」。沒有工具不裝作已產圖；不把提示詞當海報成品。

## 7｜交付與接續

先顯示實際樣稿，簡短說一個設計理由，再提供「1完成／2修改／3另出無字底圖」。無字版只在使用者選擇後製作，移除新加文字並保留原構圖及留白；不要默認移除商品包裝與Logo固有文字。需要時再確認是否包含品牌字。另要透明花字素材才處理，未實測不承諾透明PNG。

換比例先重新排版，不直接拉伸或裁掉人臉、商品與主標。多尺寸先確認第一張，再製作其餘版本。

交付圖片、實際尺寸與格式（能核對才寫）、已確認上圖文案及必要的使用說明。把需複製的文字放獨立區塊；製圖提示詞提供時用一個完整區塊。可附一份短接續摘要：用途、參考分工、保留素材、文字、配色／字形、已選版、待改。沒有儲存工具就提供可複製摘要，不說已永久記住品牌。
