# I0010｜口播與訪談讀稿

技能0.1.3 · C05影音 · 黃嘉偉KM完整包0.1.10

已有成稿 → 完整口播逐字稿 → 完整訪談稿（暖身／正題／Hook提問／三款片頭）。兩份各一個完整複製框；訪談四段全部在同一框，標示獨立一行，內容放下一行。

口播預設只整理空格與換行，不改原文。短停2個、大停5個半形空格，依詞與語意分行，不逐字拆。訪談問題不編來賓答案；末段Hook可先一句話回答，再補原因。補錄三款為待受訪者確認的建議台詞，不冒充實際回答。

```text
I0010，請用這份已確認內容，先給完整口播稿，再給完整訪談稿。
訪談包含暖身、正題、Hook提問和三款片頭，全部放在同一個複製框；標示獨立一行。
我的成稿：＿＿。
```

可接同對話I0002或KMW07成稿；其他對話看不到時請貼全文。只要其中一份可直接說。只有收尾短句且沒有主題時，先補訪談主題，不捏造內容。
