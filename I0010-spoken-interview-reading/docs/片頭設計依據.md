# 訪談片頭設計依據｜2026-11-05

本次為人工整理的適配方法，不是研究證明某種Hook一定有效。

| 方法 | 本技能運用 | 限制 |
|---|---|---|
| 懸念／問題 | 留一個具體、正文能解答的問題 | 不故意藏掉必要背景 |
| 反差／轉變 | 比較原內容支持的兩種做法或前後差別 | 不虛構逆轉或效果 |
| 重點先講 | 先交代主題／方法，再談原因和細節 | 不誇大承諾 |
| 冷開場／先果後因 | 從真實訪談精彩回答取句，後接原脈絡 | 不斷章取義 |
| 情境直入 | 有真實場景時先進入具體問題 | 不為刺激編事故 |
| 蒙太奇 | 組接多鏡頭呈現觀點、情緒或濃縮過程 | 需要畫面與剪接，不是台詞本身 |

依據：
- [YouTube觀眾留存說明](https://support.google.com/youtube/answer/9314415?hl=en)：開頭應符合標題／縮圖的期待，可把後段精彩內容提早並試不同開頭。30秒是該報表指標，不是所有影片的片頭長度。
- [Google YouTube廣告製作指南](https://services.google.com/fh/files/misc/youtube_ad_production_guide_external.pdf)：開頭可直接對觀眾說話、用出乎意料的畫面、提早用聲音，並多拍素材測不同剪法。原文前5秒建議是廣告情境，不泛化為訪談硬規格。
- [NYFA剪輯術語：Montage](https://www.nyfa.edu/student-resources/a-beginners-guide-to-film-editing-vocabulary/)：多鏡頭並置可傳達想法、情緒或濃縮故事。

以上三款台詞分類與暖身→訪談→取句→補錄流程，是依本人需求的設計選擇；尚未以真實訪談或流量測試驗證。
