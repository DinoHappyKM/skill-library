# I0009任務路由

使用者已選任務就直接接續，不為進入任何一項而先問完整十頁資料。核心判斷順序以SKILL.md為準；以下舊31代碼僅是本Skill內別名，不是額外安裝技能。

| 需求 | 來源任務 | 本次讀取與成果 |
|---|---|---|
| 不知如何賣／快速診斷 | 31A | decision-engine＋modules＋案例與策略；2個方案後選定展開90天 |
| 引流／曝光／新客 | 31E | 實際模式下的流量→承接→下一步；MK01～10按條件挑，不等於都用 |
| 漏斗／轉換／成交頁 | 31B | 斷點與話術／頁面／CTA，MK19～26及必要承接、回購 |
| 合作／KOL／異業 | 31C | 對方需求與三方收益、最小合作MVS、回流；按資料選MK05／06／08／36～40等，不因舊範圍含MK29就稱它合作模組 |
| 推薦／分享／UGC | 31D | 自願分享、獎勵條件、承接與追蹤；MK33～40按條件選 |
| 品牌定位 | 原Step1 | extended-workflows品牌段＋已知五欄；未知特色／客群給少量選項 |
| 商品組合／定價 | 原Step2商品333 | extended-workflows商品段；先問真實成本，不固定三分之一 |
| 年度／90天全套 | 原Step3、3A／3B | extended-workflows完整段；候選8～12、第一階段最多5模組 |
| 導購／檔期銷售頁 | 原銷售頁 | extended-workflows文案段；真實資訊、保障／見證缺項留待補 |
| 動機／遊戲化 | 原32 | extended-workflows動機段；內容診斷、方向選擇、小型測試 |
| PESO／公關媒體 | 原33 | extended-workflows PESO段；不把可行性冒稱95%機率 |

多任務不清時依序辨識：31A＞31E＞31B＞31C＞31D＞動機＞PESO；明確局部要求優先於預設順序。只改文案一句不啟動全套決策。
