# I0001｜日常故事貼文助手（KM 3001）

這支技能協助把真實日常小事寫成 A 反轉、B 感受、C 日常三種 FB／IG 貼文。使用者選定貼文並提供有權使用的原始照片後，再製作 9:16 繁體中文標題花字封面；重要文字需留在 IG／FB 縮圖可見範圍。
