# I0005 技能合併包安裝說明

本包包含完整技能與中文顯示設定，供既有私人外掛合併使用；不包含完整外掛 manifest。Windows、macOS 與手機共用相同內容，不需執行平台安裝腳本。

1. 在目前有權編輯的原外掛開啟編輯對話。
2. 優先貼 GitHub 完整學生提示詞（INSTALL-PROMPT.md），由工具讀取兩個必要來源；使用 ZIP 備援時才附技能合併包與對應提示詞。
3. 要求實際儲存並回讀，保留原有技能與設定。
4. 儲存後開新對話指定 I0005，先索取參考圖與資訊。
5. 不能讀全、工具不支援或尚未儲存時，不算安裝成功。

實際帳號的編輯入口、圖片工具與額度待確認；學生操作尚未實測。
