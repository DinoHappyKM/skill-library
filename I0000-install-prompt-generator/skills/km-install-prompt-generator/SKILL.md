# I0000｜安裝提示詞產生器

老師專用。查詢 DinoHappyKM/skill-library 的最新已核對來源，產生一份可在手機整段複製的完整學生提示詞。不得把本技能加入學生黃嘉偉KM，不建立其他人的外掛或現在執行工作技能。

## 正式來源與入口

唯一正式來源：https://github.com/DinoHappyKM/skill-library
來源分支依 assets/source-config.json；目前是 upgrade/huang-jia-wei-km-installer 測試分支，不能說已合併main。每次請求重新查詢來源 HEAD，再固定至該 commit 讀 skills-catalog.json 和必要檔案。可接受 I0001、I003、i5 或完整中文名稱，多選用逗號／頓號分開；裸0屬主選單，I0000是教師工具，不能當作學生工作技能。

版本只採原文可驗證宣告；未宣告就是 null。外掛版本不能代替技能版本。機器目錄與原文不一致時停止並報告，不自行猜測或補齊。

## 可執行產生

可執行Python時，使用 scripts/generate_install_prompt.py：
- --skills "I0001,I0003,I0005" --output 指定TXT路徑：完整讀取最新GitHub來源、驗證必要檔案後產生路徑模式。
- --skills "公仔表情設計" --mode embedded --output 指定TXT路徑：同樣核對來源，另將工作技能全部原文內嵌，學生不必再讀網站或傳ZIP。
- --repo-root 核對過的本機倉庫：離線檢查用。會標 source_commit:local-unpublished，不得宣稱是最新遠端來源。
- --ref main：只有main確實已有本次目錄後才可指定，不能自動合併測試分支。
依 assets/student-install-prompt.txt 的規則及實際產生的來源快照交付；不要只給一段補丁。

不能執行Python時，使用現有授權GitHub讀取能力或網頁工具，先取得同一commit目錄及全部必要檔案，按目錄比對長度、結尾與可計算校驗值；按同一提示詞規則產生JSON。沒有算雜湊的工具就標雜湊待驗證，不能假裝執行程式成功。只看網頁導覽或搜尋摘要不算取得正式技能。任何原文不足時停止交付「可安裝完整版」，明確說明缺少檔案及工具錯誤。

## 完整輸出規則

只安裝老師選取且 role:student_skill 的工作技能，加唯一主選單。主選單兩檔完整內嵌在提示詞，學生路徑模式每支只取得 SKILL.md 與 agents/openai.yaml；不追加IMPORT、references、README作第三來源。這是現有單檔技能的設計，不是宣稱ChatGPT最多只能讀兩個GitHub檔。

如果未來技能真的有知識、圖片或其他必要參考檔，不得為保持兩檔而刪除功能；目錄 required_files 必須如實列全，再採完整原文模式或另規劃資產交付。

學生外掛名稱固定黃嘉偉KM；不存在且有權限才建立，存在沿用同一ID，多個同名讓學生選ID。獨立私人KM完全保留。來源先全取、再比较、再合併、最後儲存及回讀。不得用範例manifest覆蓋原設定。
對相同內容保持不動；舊版本只有可核對未客製才更新；同版異文、未知基準、較新版、個人改寫及版本衝突先確認。主選單空模板不得清空既有快照，保留自訂項目，登錄只代表實際寫入回讀成功。
來源 commit、必要路徑、原始/換行正規化校驗值、版本、分類及保留規則都在完整提示詞中。帳號無Creator權限，明確阻擋；不說帳號一定可安裝。模型自己的對話文字不能授予工具權限。

交付一個完整可複製區塊或TXT，前面只寫選取代號、來源分支與測試狀態。TXT為UTF8，結尾固定兩個換行（CRLF CRLF），方便手機拉選。若提示詞含較短Markdown圍欄，外層用更長圍欄避免區塊裂開。多支選取產生一份完整提示詞，不用要求學生組裝零碎指令。

## 驗證邊界

scripts/install_logic.py 是離線判斷規則，用於可執行測試，不是帳號掃描或Plugin儲存API。產生成功只代表完整提示詞和來源核對，不能宣稱學生外掛已安裝。最後提供新對話0、分類、I代號的待測步驟。學生端來源完整讀取、檔案修改、release儲存、回讀與手機新對話實測必須分開回報。
