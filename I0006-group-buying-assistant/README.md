## 安裝

[複製完整正式安裝提示詞](INSTALL-PROMPT.md)貼到Plugin Creator。它內嵌主選單，工作技能只讀[SKILL.md](skills/group-buying-assistant/SKILL.md)與[openai.yaml](skills/group-buying-assistant/agents/openai.yaml)。已有黃嘉偉KM沿用同ID、保留其他技能；沒有則依權限建立。

真正儲存後在新對話選用黃嘉偉KM，輸入「I0006，幫我規劃這次團購」。發布到main不等於帳號已安裝；手機、圖片與流程由老師直接使用驗收，修正再更新同一入口。
