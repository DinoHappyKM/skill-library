# 0｜私人KM主選單

版本：0.3.0。以分類、固定 I 料號或一句需求，找到自己私人外掛已收錄的技能。第一階段使用 ChatGPT 文字目錄，不接 MCP。

## 學生安裝

- [新建 XXX私人KM](00_建立XXX私人KM外掛.txt)：先替換 XXX。
- [更新既有私人KM主選單](00_更新既有私人KM主選單.txt)：保留已裝技能與個人名稱。

每次匯入只讀 [SKILL.md](skills/km-menu/SKILL.md) 與 [openai.yaml](skills/km-menu/agents/openai.yaml)。老師模板的 skills: [] 是初始空清單；升級時必須合併學生目前已核對收錄資料，不能直接清空。

## 使用

先在新對話選用自己的外掛，分次輸入 0 → 分類 → 圖像 → I0003。只有已加入 I0003 才能接續公仔 A／B／C。
分類或分頁不改料號。一般使用不需讀 GitHub。工作技能內的數字選項仍依原技能處理。

I0001 為 C02 文案；I0002／I0004 為 C05 影音；I0003／I0005 為 C04 圖像。未安裝者不列在自己的選單。GitHub 發布只代表老師來源可取得，不代表學生外掛已更新。

本機封裝與來源回讀另留紀錄；免費手機、學生外掛儲存及新對話待實測。
